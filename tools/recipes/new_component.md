# Recipe: Creating a New Frontend Component

**To the AI Agent:**
When the user asks you to create a new UI component, strictly follow these steps:
1. Create the component file (e.g., `ComponentName.tsx`).
2. Export it as a default export or named export depending on the project standard.
3. Ensure the component uses professional icons (as per `tools/frontend/ui.md`).
4. Never hardcode text strings; extract them for translation (as per `tools/frontend/i18n.md`).
5. Create an accompanying test file (e.g., `ComponentName.test.tsx`).
