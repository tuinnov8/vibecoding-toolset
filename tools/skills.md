# Agent Skills

When executing tasks, look for and utilize the following skills/plugins:

## Global
- `security-auditor`: Run static and dynamic analysis (SAST/DAST) on code changes.
- `performance-profiler`: Analyze LCP, memory leaks, bundle size, and CPU usage.
- `accessibility-checker`: Integrate with axe-core to test UI components automatically.

## Frontend
- `modern-web-guidance`: Consult for modern UI patterns, layouts (CSS grid, flexbox), and CWV optimizations.
- `chrome-devtools`: Debug rendering, interactions, and console errors directly in the browser.

## Backend / Data
- `firebase-firestore`: Execute queries, check indexes, and validate security rules if using Firebase.
- `database-optimizer`: Inspect generated SQL queries for N+1 issues and missing indexes.
- `api-contract-tester`: Generate and validate OpenAPI specs to keep frontend and backend synchronized.
