# UI Guidelines

1. **Responsiveness**: All interfaces must be mobile-first. Ensure seamless responsiveness across all screen sizes (mobile, tablet, desktop) using modern layout techniques (CSS Grid, Flexbox) and relative units (rem, em).
2. **Optimization**: 
   - Optimize images (use WebP/AVIF) and implement lazy loading.
   - Adhere to Core Web Vitals (minimize Cumulative Layout Shift and optimize Largest Contentful Paint).
3. **Data Handling**:
   - **Validation**: Validate all user input on the client side before submission to provide immediate UX feedback.
   - **Sanitization**: Strictly sanitize any user-generated content before rendering it in the DOM to prevent cross-site scripting (XSS).
4. **Professionalism**: Minimize emojis. Use professional icons (like Lucide or Heroicons).
5. **Aesthetics**: Maintain brand colors. Avoid the overuse of heavy gradients. 
6. **Simplicity**: Prioritize clean, accessible interfaces.
